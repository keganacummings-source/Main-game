THE WALL I HIT FIRST, AND WHAT I DID ABOUT IT
---------------------------------------------

I measured before designing. The existing generator makes one plain object per
tile: at 450 x 450 that is 202,500 objects and 118 MB. At 2500 x 2500 it would
be 6,250,000 objects — about 3.6 GB — which no browser tab survives.

So the world is stored as typed arrays, one byte per tile per layer. The same
6.25M tiles come to ~30 MB and build in about 6 seconds.

    src/game/world-chart.ts     what the world IS
    src/game/world-chunks.ts    playable ground, cut a region at a time

Nothing in the chart is a playable tile. Terrain is materialised in 256 x 256
regions around the hunter (~65k tiles each, a third of the OLD whole world) and
dropped when she walks away. Regions are pure functions of the chart, so
throwing one away costs nothing but the 30ms to cut it again.


HOW A WORLD IS BUILT
--------------------

  1. CONTINENTS  a few big irregular landmasses plus scattered islands
  2. ELEVATION   ridged noise in mountain BELTS
  3. MOISTURE    its own noise, plus a bonus for being near a coast
  4. TEMPERATURE latitude, cooled by height
  5. BIOME       chosen from those three

Biomes therefore form bands and patches WITHIN a continent rather than being
painted on. Sixteen of them, up from six: deep ocean, ocean, lake, shore,
plains, forest, savanna, desert, swamp, jungle, taiga, tundra, glacier,
highland, volcanic, void.

A seed rebuilds a world exactly. That is what makes the export 8.6 KB instead
of 30 MB.

Four things went wrong on the way and are worth knowing, because each is pinned
by a test now:

  - A constant sea-level shift could only ever TAKE land away, so worlds came
    out 19% land when asked for 34%. Sea level is now a histogram cut.
  - Height taken from the same field that decides land-or-sea peaked at every
    continent's centre: each one charted as a ring of green around a round grey
    core. Land-or-sea and height are now two separate fields.
  - Height mapped straight from noise made 63% of ALL land mountain. Land
    height is now assigned by RANK through a curve, so low ground is wide and
    peaks are rare.
  - Shore judged by elevation made a THIRD of all land beach. Shore is now
    geography — land within two tiles of water. The coastline was fine all
    along; I had two beach rules fighting.


THE M MENU
----------

  src/components/world-chart-panel.tsx

It does not draw the world. It draws what you have FOUND, and the rest stays
black — walking somewhere new is the only way anything appears.

  - fog lifts in a 26-tile radius as you travel
  - named places appear in the list only once discovered
  - right-click or the star marks a favourite (kept per world seed)
  - Export chart (PNG) — a picture of what you have charted
  - Export world (JSON) — seed, continents, biome census, discovered places
  - zoom x1/x2/x3, biome census with colour swatches, continents by size

Fog is stored per 8 x 8 CELL, not per tile. Per tile would be 780 KB raw and
over a megabyte of text in every save; per cell a whole world's fog is ~12 KB,
~16 KB as text. At chart scale one cell is well under a pixel.

A fog that does not match the world it is loaded into is REFUSED and comes back
blank, rather than being loaded at the wrong offset and drawing as noise.

M falls back to the old local map whenever there is no chart, so no mode loses
its map key.


TEXTURES
--------

  scripts/sprites/world-decor.py   (idempotent, re-runnable)

Four of the new biomes were sharing art with a biome they are meant to contrast
with — savanna read as bare dirt, jungle as swamp, highland as a dungeon floor,
tundra as glacier. So four ground tiles and three scatter overlays are derived
from the existing set, the same way the caster sprites and the Engineer were:

    grass_dry, grass_jungle, stone_highland, snow_tundra
    decor_rocks, decor_bones, decor_shrub

They are recolours and the script says so plainly — nobody should mistake them
for hand-drawn art. My first pass produced a tundra indistinguishable from snow
and rocks invisible against the ground they sit on; both were retuned until the
biomes actually tell each other apart. Biomes that can honestly share art still
do (taiga and tundra are both snow, with different amounts of tree) rather than
inventing a second snow tile that would read as a bug.


WHAT IS NOT DONE — READ THIS
----------------------------

The world system is complete and tested. It is NOT wired into the engine. Open
M today and you get the old local map, because nothing creates a chart yet.

I stopped deliberately. engine.ts is 719 KB, I cannot run the game at all in
this container, and the three places this needs to hook — world creation, the
movement tick and the save — are the most load-bearing paths in it. Wiring that
blind risks breaking a game that currently works, to light up a menu.

Four calls are all it needs:

  1. WORLD CREATION (where a TURBZ world is rolled)
         import { generateChart, startSpot } from "./world-chart";
         import { setActiveChart } from "./chart-store";
         const chart = generateChart({ seed: save.seed });
         setActiveChart(chart, save.fog);
         const { tx, ty } = startSpot(chart);        // the hunter's start tile

  2. TERRAIN  — keep a RegionCache instead of one big world:
         import { RegionCache } from "./world-chunks";
         this.regions = new RegionCache(chart, 4);
         const world = this.regions.at(chartTx, chartTy);
     A region IS a WorldData, so collision, rendering and the builder are handed
     exactly what they are handed today.

  3. MOVEMENT  — one line wherever the hunter's tile changes:
         import { noteVisited } from "./chart-store";
         if (noteVisited(chartTx, chartTy)) this.powerDirty = true;  // or mark the save dirty
     It returns 0 when nothing new was uncovered, which is almost every step.

  4. SAVE  — persist and restore the fog:
         import { fogForSave } from "./chart-store";
         save.fog = fogForSave();                    // on save
         // on load it goes to setActiveChart above as the second argument

Say the word and I will do the wiring as its own pass, with the engine changes
kept small and separate so they are easy to review or back out.
