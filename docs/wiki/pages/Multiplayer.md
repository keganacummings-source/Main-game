# Multiplayer

Play with up to **3 witches** in one lobby.

## Lobbies

Open **Lobby** (**L**):

- **Create lobby:** you become the **host**. Share the code shown (copy button).
- **Join:** type a friend's code (3–6 letters and numbers).
- **Leave lobby** at any time.

A lobby only exists while its host is online. Players connect directly to each other once they find each other through the server.

## How it works

- The **host's game runs the world**: foes, their health, dungeon rifts and drops. Guests see the host's foes and send their hits to the host.
- Everyone sees each other's witch, outfit, gear effects and level.
- When the host changes map (dungeon, rift), the party follows.
- The host's dungeon rifts are shared with the lobby.

## Chat

The chat window has three tabs:

- **Party:** your lobby.
- **Global:** everyone online.
- **Friends:** add friends in **Options** on the hub.

## Notes

- Player-to-player trading is currently not available. **T** opens the Black Market.
- Each player keeps their own save, gear and progress.
