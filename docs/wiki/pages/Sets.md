# Sets

There are **100 armor sets**: 20 for each race. Every armor drop (head, chest, legs, feet, relic) belongs to one.

## In short

- Wear **all five pieces** of one set (head, chest, legs, feet and relic) to switch on its **aura**. In combat, the aura pulses every 6.2 seconds and hits everything within 120 px.
- **Collect** all five pieces of a set while playing a class and that set is **unlocked for that class**.
- When a witch of that class dies, the next one can **wake wearing a level-1 copy** of the set, bonus included.

## Reading a set's bonus

- The **active set's** bonus is pinned under the WORN block in the Bag.
- Every **gear card** shows the bonus for that card's set as a visible line under its tags.
- Every **set-progress row** (under *Set & enchant totals*) shows the bonus beside the set name.

## Per-piece armor silhouettes (Crying Girl)

The Crying Girl draws through a paper-doll instead of a static sprite. Each gear slot — head, chest, legs, feet, relic, hands — paints its own pixel-art silhouette on top of her base body, in that piece's element colour. The slot kit covers crowns / horns / veils / tiaras for the head; round / spiked / winged pauldrons and chest sashes for the chest; round, diamond, double and chain belts for the legs; ankle through thigh-high boots with cuffs and greaves for the feet; short / long / hooded capes and wing mantles for the relic; and bracers, gauntlets, claws and bandage wraps for the hands.

Pieces **stack visually, like Terraria**: wear a chest from one set, legs from another and boots from a third and all three silhouettes read at once, each in its own tint. The five-piece set aura is the signal that a full set is on, drawn behind her sprite — the piece visuals themselves do not change when the set completes.

## Set auras

Each set uses one of ten aura kinds, which decides its pulse. The written bonus on each set is its flavour; the pulse is what it actually does.

The pulse damage is 18 + 2 × your level (28 + 2 × level for Solar Nova and Blood Moon). Its effects follow the usual [status rules](Status-Effects) (no stacking, immunity). Each set also has its own look: tint, size, spin, crest and burst. See [Gear FX](Gear-FX).

## Unlocking a set

- Any time you **hold** a set piece (picked up, bought, looted or traded), that slot counts as **found** for the class you are playing.
- When a class has found all five slots of one set, you get *"Set unlocked for <class>"*.
- The Bag's **Set & enchant totals** lists this class's progress (for example 3/5) for every set it has started.
- On the rebirth screen, pick that class and choose the set under **Spawn gear**. Class cards show how many sets each class has.
- Any race's set works for any class, as long as **that class** collected it.
- Older saves keep their finished sets: each one goes to every class of that set's race.

## Under the hood

- A level-1 set copy rolls Common quality (Fine once your account is level 10+) with a bit of luck.
- The set bonus is active whenever all five armor pieces share one set. The weapon doesn't count.
- 62% of armor drops come from your race's sets.
